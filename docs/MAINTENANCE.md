# Profile README maintenance

## Scope

This repository change is a GitHub profile README and its supporting artwork. It has no site, JavaScript application, deployment workflow, or Pages dependency. GitHub READMEs cannot run custom pointer or scroll-driven rendering. The faceted instrument is original SVG artwork; its orbital dash has a slow CSS loop where GitHub's image renderer supports it. The composition is complete when animation is unavailable or reduced motion is preferred.

The responsive desktop and mobile heroes are generated by `python scripts/generate_hero.py`. Project diagrams and the research atlas are generated by `python scripts/generate_assets.py`. Both scripts use only the Python standard library. Keep the hero generators separate: the project-art script does not overwrite the current hero.

## Profile counter

The prominent Hits.sh badge uses key `github.com/Aayush-Kadam` with no `extraCount`. Hits.sh counts provider-served image requests for that key, including repeat loads and previews. GitHub's image cache can coalesce or delay requests. It is not a verified count of unique visitors or all GitHub profile views. Provider documentation: https://github.com/silentsoft/hits

## Factual and visual boundaries

`docs/SOURCES.md` records the public sources checked for project descriptions. Keep pre-release, finite-domain, synthetic, working-paper, and licensing boundaries close to each claim. The only personal contact destination is the owner-supplied LinkedIn URL.

The SVGs contain titles, descriptions, static artwork, and no external image imports, scripts, or embedded links. The README image elements have alternative text. The CSS loop includes a `prefers-reduced-motion` fallback. GitHub and downstream image proxies may choose to show the static frame; the text and visual do not rely on motion. Verify desktop, narrow viewport, and both themes on the rendered branch after changing artwork.

The removed Observatory V2 website remains recoverable through ordinary Git history at commit `4f1942755512e5ef68805573eca9b8d0402c03df`. It is intentionally absent from this README-only PR's final file tree.

Run `python scripts/validate_profile.py` after edits. No package install or build step is needed.
