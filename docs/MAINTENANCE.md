# Observatory V2 / maintenance

## Two surfaces

The GitHub profile README is a native Markdown gateway. Its hero is an optimized WebP capture from the actual WebGL portfolio in Chrome, not a claim that JavaScript runs on GitHub. The desktop and mobile captures are in assets/hero/observatory-v2*.webp; the uncompressed review screenshots are kept in the task's local outputs. The featured engineering diagrams remain original vector assets generated by scripts/generate_assets.py. Their source is retained for reuse and correction.

The interactive site lives in site/. The central polyhedron, core, rings, trajectories, discrete project nodes, lighting, and camera are real Three.js objects. site/src/main.ts owns chapter mapping, pointer and drag response, project raycasting, reduced-motion behavior, WebGL fallback, rendering quality, and resource cleanup. site/src/style.css owns responsive composition. The site relies on no backend or paid infrastructure. It does not collect website analytics.
